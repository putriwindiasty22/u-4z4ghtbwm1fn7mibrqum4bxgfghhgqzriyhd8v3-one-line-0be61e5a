**One Line, One Laugh** — a single funny line. `main.ts` (Node 22, no network, no dependencies) writes the line to `/output/entry.txt` (falling back to `./output/entry.txt` when run locally).

The joke turns a productivity tool against its owner: telling your calendar you're too busy to meet is exactly the kind of input a calendar treats as a scheduling request, so it books a meeting about being too busy. The twist is instant, the logic is airtight, and nobody had to leave their desk. The line is 78 characters, inside the 140-character gate.

## Run it

```sh
node main.ts
```

Then read `output/entry.txt` (or `/output/entry.txt` in the grading sandbox).
